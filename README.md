# Projeto Raízes do Nordeste - Back-End (Uninter)

API REST desenvolvida em Java e Spring Boot para gerir o ecossistema da rede de lanchonetes, suportando múltiplos canais (`APP`, `TOTEM`, `WEB`, `BALCAO`).

## Stack Tecnológica
- **Java 25**
- **Spring Boot 4.1.1**
- **PostgreSQL** (Base de dados relacional)

## Pré-requisitos
- JDK 25 instalado
- Maven instalado
- PostgreSQL localmente

## Documentação da API e Evidências

- **Repositório Público**: https://github.com/julianastefani/raizes-nordeste-api
- **Documentação Swagger (OpenAPI)**: 
  - Após iniciar a aplicação, acesse localmente através da URL: `http://localhost:8080/swagger-ui/index.html`
- **Coleção Postman / Testes**:
  - A coleção de testes ou os scripts de validação encontram-se disponíveis na raiz do projeto (ou podem ser consultados através do ficheiro de testes integrado).
